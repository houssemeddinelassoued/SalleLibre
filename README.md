
## SALLE LIBRE

Ce projet est une API de réservation de salles

Fonctions : 
- Vérifier la disponibilité des salles
- Réserver une salle
- Libérer une salle
- Consulter l'historique des réservations

Technologies utilisées :
Typescript
- Node.js
- Express
- PostgreSQL
- TypeORM
- JWT (JSON Web Token)
